# 🍽️ مَذاق | Mazzaq

**Mazzaq** is a full-stack recipe management platform designed to provide users with an interactive experience to discover, explore, and manage recipes.

The platform includes a modern user interface, secure authentication, recipe management, and a dedicated admin dashboard for managing recipes and users.

This project was my first complete **Full-Stack application**, where I worked on both frontend and backend development, connecting the entire application through RESTful APIs.

## ✨ Features

- 🔐 **Authentication & Authorization** – Secure user registration and login using JWT.
- 🍲 **Recipe Management** – Create, view, update, and delete recipes.
- 🖼️ **Image Upload** – Upload and manage recipe images using Cloudinary and Multer.
- 📊 **Admin Dashboard** – Manage recipes and users with dashboard analytics.
- 🔎 **Recipe Discovery** – Browse and explore available recipes.
- 🛡️ **Protected Routes** – Role-based access control for restricted features.
- 📱 **Responsive Design** – Optimized experience across different screen sizes.
- ⚡ **Form Validation** – Reliable form validation using Zod.
